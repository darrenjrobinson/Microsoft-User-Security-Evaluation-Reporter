User security summary

Risk events

This check looks for user risk events such as malware-linked IPs, anonymous IP (Tor/VPN) and atypical travel. Evaluate any risks in the context of the user, their position and other recent activity.

Registered MFA methods

This check lists the user's registered multifactor authentication methods. The preferred primary method is Microsoft Authenticator or a passkey. Text message (SMS) and voice should be avoided and used only where the user has no compatible device.

Pwned check

This check looks up the user's email address in Have I Been Pwned breaches and pastes, alongside Entra ID Protection leaked credentials detections. If a password has been exposed it is strongly recommended the user changes it, to mitigate password spray and credential stuffing attacks.

Recent sign-in activity

Review recent sign-ins alongside risk events and password resets to spot unusual activity for the account. For Windows desktop sign-ins, a Microsoft Entra joined device is strongly recommended.
